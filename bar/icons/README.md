# Built-in icons

The icons pila-bar and pila-osd draw (`bar/src/symbols.rs`), built into the programs so no
icon font has to be installed: unchanged SVG files from
[Material Design Icons](https://pictogrammers.com/library/mdi/) by Pictogrammers, version
7.4.47 (the npm package `@mdi/svg`), under the Apache License 2.0 (`LICENSE`, the
collection's, and `LICENSE-APACHE-2.0`, the license itself).

A new one comes from the same package, by its file name in `svg/`, and is added to
`symbols.rs`' list.
